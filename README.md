# Retrotink-DV1-Profile-Repository

## Nonsense
This repository is a collection of Tink4K profiles that have been cropped and scaled correctly. You can download an entire set for a specific profile, or use the monthy release zip to use the collection of profiles (the monster who maintains this repo uses that set).

**Note: The profiles style were created and maintained by the amazing creators in the Retrotink community. The only thing the author of this repo has done is crop and scale them for the MiSTer's DV1 feature**

## Installation
### Monthly Pack
Unzip the pack into the profile/DV1 folder on your Retrotink 4K's SD Card.

Make sure your MiSTer has `direct_video=1` enabled in your MiSTer.ini and that **Auto-Load DV1** Profiles is set to **ON** in the Retrotink's Profile Menu.

**These profiles require Tink4K firmware 1.72.0 or later and should be compatible with both the CE and Pro models (although you won't get rotation on the CE).**

## FAQ

### Can I request a set based on different CRT profiles?
Totally. Please post an [issue](https://github.com/TheJesusFish/Retrotink-DV1-Profile-Repository/issues) for the combo you'd like. If an issue already exists, just +1 it. If something gets a bunch of votes, or I find it interesting, I'll make a set and add it to the releases.
